Ad Block (Android, Kotlin)

1. Android Studio (Hedgehog ya naya) me "Open" -> AdBlockApp folder.
2. Gradle sync hone do (internet chahiye).
3. Real phone pe Run karo (emulator pe bhi chalta hai).
4. "Turn ON" dabao -> system "Connection request" popup -> OK.
5. Notification shade -> edit (pencil) -> Ad Block / Wi-Fi / Bluetooth tiles add karo.

Better blocking: app/src/main/assets/blocklist.txt me bada list daalo
(StevenBlack hosts ya AdGuard DNS filter).
Phone me "Private DNS" OFF/Automatic rakho, warna DNS app ko bypass kar sakta hai.
